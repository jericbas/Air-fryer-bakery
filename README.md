## 🚀 Quick Start

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Run tests
bun test

# Build for production
bun run build
```

Visit `http://localhost:5173/Air-fryer-bakery/` to see the app.

---

## ✨ Features

- **Baker's Math Engine**: Professional percentages (flour = 100%)
- **Multiple Recipe Modes**: Bread, Cake, Cookies
- **Special Rules**: Condensada Rule, Fruit Soaking, Tangzhong
- **Air Fryer Presets**: 5 common models with optimized temps/times
- **Diabetic Mode**: Sugar substitutions (erythritol, monkfruit, allulose)
- **Smart Instructions**: Contextual warnings, tips, step-by-step with temp/time
- **Recipe Scaling**: Adjust yield weight with comparison table
- **Dough Profile**: Visual texture prediction (softness/richness/chewiness)

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript 6 (strict)
- **Build**: Vite 5 + Bun
- **Styling**: Tailwind CSS 4 (CSS-first) + DaisyUI 5
- **Testing**: Vitest
- **Linting**: Biome
- **Icons**: Lucide React
